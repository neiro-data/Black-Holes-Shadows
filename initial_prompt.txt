This repository contains the original codes that generate the Black Holes shadows for a Schwarzschild black hole with a superposition of a thin disk with mass.

Characteristics of the codes:
 - desorganized
 - have duplicated code
 - not commented

What the code has?
 - Mathematical methods for ODEs, integration, derivatives
 - Functions that correspond physical quantities such as spacetime metrics for different spacetimes, their derivatives, etc
 - the most compute heavy parts of the code are within functions that are decorated with @jit(nopython = True) from numba
 - there is also a lot of comented code (which can or not be duplicated) and that eventually can be deleted. Still needs to be analyzed
 - the plotting part - after the numerical calculations are done, there are plots with multiple colormaps possible of the results
